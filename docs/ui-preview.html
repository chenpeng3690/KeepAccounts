已确认的设计决策

下面六项已经按你的意见定稿，实现时不再改动。

  1. 主色：靛蓝 #3B5BDB
    避开红绿（红绿已经占给支出/收入），支出 #E03131、收入 #0CA678、提醒 #C2760A。
  2. 首页首屏：本月支出
    净资产放在「资产」Tab。打开 App 多数时候是在看这个月花了多少，净资产变化慢，看一次就够。
  3. 规则向导：保持 8 步
    不压缩。配置是一次性动作，慢一点但不容易配错，比每屏塞满信息更适合小白。
  4. 导航：5 个 Tab，待确认独立
    顺序 账单 / 资产 / 待确认 / 统计 / 设置。设置保留为第五个 Tab 而不是藏进右上角——因为里面装着「通知使用权状态」，服务被杀后需要随时能查。待确认用角标提示，0 条时不显示角标。
  5. 解析日志：对用户开放
    入口放在待确认 Tab 的空态与底部，不绕设置。透明度换取信任——能查「它到底记了些啥」，才敢让它自动记账。
  6. 记账浮悬提示：用系统横幅，不要悬浮窗
    付款时人不在这个 App 里，应用内提示等于没有。用通知的 heads-up 横幅实现，不申请 SYSTEM_ALERT_WINDOW。三档开关：全部提示 / 仅成功入账 / 不提示。
